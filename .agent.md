# `llm-sdk-claude-agent` — agent integration guide

A production harness around the **Claude Agent SDK** (`@anthropic-ai/claude-agent-sdk`). Node ESM only
(`.mjs`, `"type": "module"`).

## Install

```bash
npm install llm-sdk-claude-agent
```

Pulls `@anthropic-ai/claude-agent-sdk`, which resolves and spawns the Claude Code CLI as a subprocess.

## Auth

Set one of (resolved from the environment by `runtime.mjs`, which fails fast if none are present):

- `ANTHROPIC_API_KEY` — direct Anthropic API
- `CLAUDE_CODE_USE_BEDROCK=1` — Amazon Bedrock
- `CLAUDE_CODE_USE_VERTEX=1` — Google Vertex AI

Override the CLI binary with `pathToClaudeCodeExecutable` (config) or `CLAUDE_AGENT_EXECUTABLE` (env).

## Entry points

```js
import { createHarness, ClaudeAgentHarness, formatSSE } from 'llm-sdk-claude-agent';
```

- `createHarness(options, deps?)` — factory (constructs + `start()`).
- `ClaudeAgentHarness` — the class (extends `EventEmitter`).
- `formatSSE(item)` — frame a `stream()` item as a Server-Sent-Events string.
- Runtime helpers: `resolveExecutablePath`, `resolveAuth`, `createQuery` (from `./runtime`); the
  underlying SDK's `query` / `tool` / `createSdkMcpServer` are resolved internally.

### Primary methods

| Method | Purpose |
| --- | --- |
| `chat(prompt, opts?)` | buffered run → `{ content, usage, sessionId, costUsd, numTurns }` |
| `stream(prompt, opts?)` | async generator of `{type:'delta'}` … `{type:'done'}` |
| `structured(prompt, schema, opts?)` | validated JSON output + auto-repair |
| `registerTool({ name, description, parameters, handler })` | in-process `mcp__harness__<name>` |
| `preflight(prompt, opts?)` | heuristic token report (no dispatch) |
| `usageSummary()` / `usageReport()` | structured / human-readable usage |
| `resumeSession(id)` / `continueFrom(id)` / `forkSession(id)` | native sessions |
| `on(event, fn)` | subscribe to lifecycle events |
| `stop()` | release + fire `onSessionEnd` |

### Minimal snippet

```js
const h = await createHarness({ config: { model: 'claude-opus-4-8' } });
const { content } = await h.chat('...');
await h.stop();
```

See the README [config table](README.md#configuration) and
